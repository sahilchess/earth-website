Objective: Create a multi-page website about your "Dream Destination" using HTML and CSS. The website should include at least three pages, appropriate styling, and a variety of HTML elements. Demonstrate your understanding of advanced CSS selectors, pseudo-classes, and pseudo-elements, as well as animations.

Project Requirements:
Structure:
Minimum of 3 Pages:
Home Page: Introduction to your dream destination, a brief description, and a navigation menu.
Destination Attractions: List and describe at least three key attractions or activities in your destination.
Travel Guide: Include information like best times to visit, cultural tips, travel requirements, etc.
Navigation: All pages must link to each other using a consistent navigation menu.
Ensure your code is properly indented, with proper nesting of tags.
HTML Elements:
Use headers (<h1>, <h2>, etc.) and paragraphs (<p>).
Include images (<img>) to showcase your destination.
Create a list (<ul> or <ol>) of recommended places to visit or things to do.
Add at least one iFrame element, such as a map of your destination or an embedded video related to it.
CSS Styling:
Use an external CSS file to style your website.
Utilize advanced CSS selectors (you must use AT LEAST 2 of the 4):
Descendant selectors: e.g., .container p
Child selectors: e.g., .menu > li
Adjacent sibling selectors: e.g., h1 + p
General sibling selectors: e.g., h2 ~ p
Implement pseudo-classes: e.g., :hover, :active, :nth-child().
Implement pseudo-elements: e.g., ::before, ::after.
You must use at least one of the above pseudo-classes or elements in your code.
Use flexbox or grid for page layout.
Animations:
Create at least one CSS animation using @keyframes. Examples:
A fading in effect on the homepage text.
A bouncing button or an image scaling on hover.
Styling and Layout:
Ensure proper use of margins, padding, and positioning for a clean layout.
Use color schemes and font styles that are visually appealing and related to your destination.
